**FarmDirect** is a hyper-local agricultural marketplace connecting local farms directly with consumers and wholesale buyers. Built with modern React, TypeScript, and Tailwind CSS.

---

## 🌾 Features

- **Direct Farmer-to-Consumer Commerce**: Cut out intermediaries with transparent farm sourcing.
- **Interactive Product Catalog**: Organic vegetables, seasonal fruits, dairy, and artisanal goods.
- **Farm Detail Explorer**: Learn about sustainable farming practices, harvest dates, and farmer profiles.
- **Shopping Cart & Checkout Drawer**: Seamless slide-over cart with live quantity management.
- **Backend & Django Integration Ready**: Designed with modular API services and Django schema integration.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide React Icons
- **State & Data**: Custom React hooks, typed mock data layer

---

## 🚀 Getting Started

```bash
# 1. Clone repository
git clone https://github.com/Mercyy00/FarmDirect.git

# 2. Navigate to project
cd FarmDirect

# 3. Install dependencies
npm install

# 4. Start development server
npm run dev
```

Visit [http://localhost:5173](http://localhost:5173).
